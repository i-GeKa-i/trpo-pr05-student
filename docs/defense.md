# Материалы для защиты

## Сценарий демонстрации

1. Открыть главную — 12 карточек, средняя цена 1 192,75 ₽.
2. Выбрать категорию «Оборудование» — 4 товара.
3. Включить «Только в наличии» — товары 5 и 10 скрыты.
4. Открыть `/?category=abc` или `/?category=99` — сообщение «Такой категории нет», показан весь каталог, без PHP warning.
5. Испортить строку в `data/products.json` (очистить `name`) — над каталогом появится список пропущенных строк, остальные товары выводятся.

## Ответы на контрольные вопросы

1. **Входные данные:** `data/products.json`, `data/categories.json` и GET-параметры фильтра.
2. **Преобразование в интерфейс:** `CatalogService` создаёт объекты, циклы в `public/index.php` выводят карточки.
3. **Проверенное ошибочное состояние:** неизвестная или нечисловая категория, битые строки dataset, отсутствующий файл (см. `tests/check.php`).
4. **При росте проекта:** автозагрузка классов (PSR-4), отдельный слой чтения данных, контроллеры и шаблоны.
5. **Проверка после клонирования:** команды из раздела «Запуск» README и `php tests/check.php`.
6. **PHP и JavaScript:** PHP выполняется на сервере и отдаёт готовый HTML; JavaScript работает в браузере после загрузки страницы.
7. **Когда полезен конструктор:** он не даёт объекту существовать в невалидном состоянии.
